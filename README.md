# PS---Restaurant-System

Sistema de restaurante y delivery por consola con arquitectura modular, validaciones exhaustivas y pruebas unitarias.

## Requisitos
- Python 3.10 o superior
- Dependencias en `requirements.txt`

## Instalación
```
pip install -r requirements.txt
```

## Ejecución
```
python app.py
```

## Pruebas
```
python -m pytest
```

## Estructura
- `src/`: implementación modular (menú, órdenes, mesas, meseros, delivery, clientes)
- `tests/`: pruebas organizadas por módulo
- `IMPLEMENTS.md`: arquitectura y estrategias de validación/testing
